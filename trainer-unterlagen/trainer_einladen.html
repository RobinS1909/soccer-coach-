Soccer Coach – Ablauf: Trainer einladen
App: training.svsoltau.de  ·  Datenbank: supabase.com/dashboard → Projekt soccer-coach  ·  Dauer: ca. 5 Minuten

A · Neuen Trainer hinzufügen

1
Konto anlegen – in Supabase: Authentication → Users → Add user → Create new user
E-Mail des Trainers + Startpasswort (mind. 10 Zeichen), Haken bei „Auto Confirm User“ → Create user
am besten am Computer; nur Robin hat den Supabase-Zugang
2
Freischalten – in der App: Trainer → anmelden → Reiter „Team“
gleiche E-Mail eintragen → Freischalten (Meldung „… ist jetzt Trainer“)
3
Zugang weitergeben – persönlich oder per Nachricht: App-Adresse training.svsoltau.de, E-Mail und Startpasswort
Tipp: Passwort getrennt von E-Mail/Adresse schicken oder mündlich sagen
4
Neuer Trainer: App öffnen → Trainer → anmelden → Team → „Mein Passwort ändern“ → eigenes Passwort festlegen ✓

B · Trainer entfernen

App → Trainer → Team → bei der E-Mail „Entfernen“. Danach kein Zugriff mehr auf Kinderdaten.
Optional zusätzlich in Supabase: Authentication → Users → Nutzer löschen.

C · Passwort vergessen

App → Trainer → E-Mail eintragen → „Passwort vergessen?“ → Link in der Mail.
Kommt keine Mail (Gratis-Tarif verschickt nur wenige Mails): in Supabase Nutzer löschen, neu anlegen (Schritt 1) und wieder freischalten (Schritt 2).

D · Kinder hinzufügen

Nur wenn die unterschriebene Einwilligung vorliegt: App → Trainer → Kinder → einzeln oder „Viele Kinder auf einmal anlegen“ → „Als Code-Karten drucken“. Codes werden nur einmal angezeigt.

Gut zu wissen

  • Trainer sehen alle Kinder und dürfen Kinder anlegen und löschen – nur vertrauenswürdige Personen freischalten.
  • Der letzte Trainer kann nicht entfernt werden (damit sich niemand aussperrt).
  • Supabase pausiert das Projekt nach 7 Tagen ohne Nutzung (z. B. Sommerpause) → im Dashboard auf „Restore“ tippen.
  • Den Supabase-Zugang (Konto von Robin) niemals weitergeben – Trainer brauchen nur ihren App-Zugang.
