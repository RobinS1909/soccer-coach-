# Monatlicher Übungs-Nachschub

Jeden Monat kommen **15 neue Übungen** dazu – verteilt auf alle Schwerpunkte
(Umschalten, Passen, Spiel über den Dritten, freie Räume, Abwehr, Ballgefühl).

## Ablauf
1. Am 1. des Monats schreibt Claude automatisch 15 neue, eigene Übungen
   (Heimtraining, kleiner Raum, kindgerecht, inkl. Kopf-Training mit Spielfeld-Skizzen).
2. Claude prüft sie mit `node scripts/pruefe-uebungen.mjs` und im Browser.
3. Claude stellt sie bei GitHub als **Pull Request** ein und du bekommst eine Benachrichtigung.
4. **Du entscheidest:** Pull Request öffnen → Liste durchsehen → **„Merge pull request“**.
   Erst dann erscheinen die Übungen in der App. Oder Claude im Chat „OK“ schreiben.

## Regeln für neue Übungen
- Eigene Texte – keine Inhalte aus Bezahl-Plattformen (z. B. ADVANCE.FOOTBALL, 1x1SPORT) kopieren.
  Ideen von dort in eigenen Worten beschreiben ist in Ordnung.
- Machbar zu Hause: Wand, Garten, Flur; höchstens ein Helfer aus der Familie.
- Kurze, kindgerechte Sätze; 5–10 Minuten; 3–6 Schritte; ein Profi-Tipp.
- Keine Kopfball-Übungen (Empfehlung im Kinderfußball).
