Anleitung für Eltern und Kinder

1. App öffnen

Ihr bekommt vom Trainerteam einen Link und einen Code (6 Zeichen, z. B. K7M2QX). Den Link im Handy-Browser öffnen. Eine Installation aus dem App-Store ist nicht nötig.

2. Auf den Startbildschirm legen (empfohlen)

iPhone (Safari)Android (Chrome)
  1. Link in Safari öffnen
  2. Unten auf das Teilen-Symbol tippen (Quadrat mit Pfeil nach oben)
  3. „Zum Home-Bildschirm“ wählen → „Hinzufügen“
  1. Link in Chrome öffnen
  2. Oben rechts auf ⋮ tippen
  3. „App installieren“ oder „Zum Startbildschirm hinzufügen“

Danach gibt es ein gelb-schwarzes „Soccer Coach“-Symbol wie bei einer normalen App. Die Übungsanleitungen funktionieren dann auch ohne Internet.

3. Code eingeben

Beim ersten Öffnen den Code eingeben und auf „Los geht’s!“ tippen. Das Handy merkt sich den Code. Code verloren? Kein Problem – das Trainerteam erstellt einen neuen.

4. Trainieren

  • Unter „Woche“ stehen die Pflicht-Einheiten. Der gelbe Balken zeigt, wie viel schon geschafft ist.
  • Übung antippen → Anleitung lesen → trainieren → „Geschafft! ✓“ tippen.
  • Kopf-Training 🧠 sind kurze Quizfragen mit Spielfeld-Bildern.
  • Unter „Abzeichen“ sammelt dein Kind Belohnungen.

5. Unsere Wochenregel

Alle machen die Pflicht-Einheiten der Woche.

Beim Training gefehlt? Dann kommen pro verpasstem Training 2 Extra-Einheiten dazu. Die App zeigt das automatisch an.

Tipps für Eltern

  • Für Wandpässe am besten eine Garagen- oder Hauswand ohne Fenster nutzen – vorher fragen, ob das okay ist.
  • Manche Übungen brauchen einen Helfer: 5 Minuten mitmachen reicht und macht den Kindern doppelt Spaß.
  • Lieber 3× pro Woche 10 Minuten als einmal eine Stunde.
  • Bitte ehrlich abhaken lassen – es geht ums Besserwerden, nicht um Punkte.
